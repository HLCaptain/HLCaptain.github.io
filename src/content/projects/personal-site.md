This site is built as a small publishing system instead of a landing page. Content is stored in typed
Markdown collections, the interface is static by default, and the sidebar is designed for repeated
navigation rather than one-time discovery.

## Constraints

The design target is a modern adaptation of warm mechanical minimalism: restrained panels, pixel
glyphs, precise state changes, and motion that supports orientation.
